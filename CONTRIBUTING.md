# Cómo participar

Gracias por tu interés en **Vecipp IA**. Vecipp es software propietario: este repositorio no recibe
contribuciones de código, pero tu experiencia sí nos ayuda a crecer.

- **¿Encontraste un error?** Abre un *issue* con la plantilla «Reportar un error».
- **¿Tienes una idea?** Abre un *issue* con la plantilla «Proponer una mejora».
- **¿Necesitas ayuda con tu cuenta?** Escríbenos en [soporte.vecipp.com](https://soporte.vecipp.com).
- **¿Una vulnerabilidad?** No la publiques: sigue [SECURITY.md](SECURITY.md).

Todas las conversaciones siguen el [Código de conducta](CODE_OF_CONDUCT.md).
